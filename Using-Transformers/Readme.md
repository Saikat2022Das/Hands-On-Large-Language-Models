# Behind Tokenizers and Transformers

This repository contains two Jupyter notebooks that explain how Transformer-based NLP models work internally using the Hugging Face `transformers` library.

## Files

### 1. Behind_The_Tokenizers.ipynb
This notebook explains how raw text is converted into tokens and numerical IDs using a tokenizer. It demonstrates tokenization, padding, truncation, and how tokenizers prepare text for Transformer models.

### 2. Behind_the_Transformers_model.ipynb
This notebook shows how a Transformer model processes tokenized inputs and generates predictions. It covers preprocessing, model inference, and postprocessing using Hugging Face models and pipelines.

## What You Will Learn

- How text is converted into tokens
- How tokenizers generate input IDs
- How Transformer models process tokenized inputs
- How Hugging Face pipelines simplify NLP tasks
